# WinRM (5985, 5986)

---

## Overview

`Windows Remote Management` (`WinRM`) is Windows' integrated **command-line-based remote management protocol**, implementing the **WS-Management** protocol using **SOAP** to connect to remote hosts and applications.

- Ports: **TCP 5985** (HTTP) and **TCP 5986** (HTTPS)
	- Historically ports 80/443 were used, but 80 was mainly blocked for security reasons → dedicated ports adopted
- Must be **explicitly enabled and configured starting with Windows 10**
- **Enabled by default since Windows Server 2012**; older servers/clients need configuration + firewall exceptions
- In practice we often see only HTTP (**TCP 5985**) used instead of HTTPS

#### Related Components

|**Component**|**Role**|
|---|---|
|WinRS (Windows Remote Shell)|Execute arbitrary commands on the remote system; included by default even on Windows 7|
|PowerShell remoting / event log merging|These services *require* WinRM|

## Footprinting the Service

#### Nmap

```
tylapcheong@htb[/htb]$ nmap -sV -sC 10.129.201.248 -p5985,5986 --disable-arp-ping -n

PORT     STATE SERVICE VERSION
5985/tcp open  http    Microsoft HTTPAPI httpd 2.0 (SSDP/UPnP)
```

The `Microsoft HTTPAPI httpd 2.0` fingerprint on 5985 = WinRM listener present.

#### Test Reachability

- From Windows PowerShell: the `Test-WsMan` cmdlet (pass the hostname in question) tells us if remote servers can be reached via WinRM.
- From Linux: go straight to `evil-winrm`.

## Connecting — evil-winrm

Purpose-built pentest tool for interacting with WinRM:

```
tylapcheong@htb[/htb]$ evil-winrm -i 10.129.201.248 -u Cry0l1t3 -p P455w0rD!

*Evil-WinRM* PS C:\Users\Cry0l1t3\Documents>
```

Drops us directly into a full PowerShell session on the target.

## Workflow Cheat Sheet

1. Nmap `-p5985,5986` → look for `Microsoft HTTPAPI httpd 2.0` on 5985 (WinRM over plain HTTP is common)
2. Windows-native check: `Test-WsMan <host>`
3. With credentials: `evil-winrm -i <IP> -u <user> -p <pass>` → interactive PS shell
4. Remember WinRM access ≈ PowerShell remoting → strong lateral movement primitive once any AD creds are found
